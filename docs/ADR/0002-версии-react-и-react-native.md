# ADR-0002. Жёсткое закрепление версий React и React Native

**Дата:** 2026-09-09
**Статус:** принято

## Контекст

В корневом `package.json` есть раздел `overrides`, который прибивает три
пакета к точным версиям:

```json
"overrides": {
  "react": "19.2.3",
  "react-dom": "19.2.3",
  "react-native": "0.86.3"
}
```

Это выглядит как излишняя строгость, поэтому объясняю причину — иначе кто-то
однажды уберёт эти строки «для порядка» и потратит полдня на поиск.

## Проблема

В монорепозитории три приложения: сервер, веб-панель и мобильное приложение.
Веб-панель и мобильное приложение оба используют React, но требуют разных
версий: Next.js работает с любой свежей, а Expo SDK 57 совместим строго
с React 19.2.3 и React Native 0.86.3.

Без закрепления npm устанавливает **две копии** React: одну в корне для
панели, другую внутри `apps/mobile`. Дальше начинается интересное:

- Сборщик Metro находит не ту копию React Native, что ожидает Expo,
  и падает с сообщением про отсутствующий файл `rn-get-polyfills`.
  По тексту ошибки понять причину невозможно — она про пути внутри пакета,
  а не про версии.
- Две копии React в одной сборке дают «невозможные» сбои: хуки перестают
  работать, состояние теряется, ошибки указывают куда угодно, кроме причины.

## Решение

Одна копия каждого пакета на весь репозиторий, версии — те, которых требует
Expo. Панель управления на React 19.2.3 работает без единой оговорки.

## Как менять версии в будущем

Только вместе с обновлением Expo SDK и только его же командой:

```bash
cd apps/mobile
npx expo install --check   # покажет, что не совпадает
npx expo install --fix     # приведёт к совместимым версиям
```

Затем перенести полученные версии в корневые `overrides`, удалить
`package-lock.json` и `node_modules` и установить заново. Без полного
удаления старые версии остаются в дереве зависимостей и всё повторяется.

## Признак, что это снова случилось

```
Package subpath './rn-get-polyfills' is not defined by "exports"
```

Проверить количество копий:

```bash
find . -maxdepth 4 -type d -path "*/node_modules/react-native"
```

Должна быть ровно одна строка.
