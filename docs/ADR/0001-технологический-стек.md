# ADR-0001. Технологический стек и структура проекта

**Дата:** 2026-09-09
**Статус:** принято

> ADR (Architecture Decision Record) — короткая запись о принятом техническом
> решении: что решили, почему, и от чего отказались. Нужна, чтобы через год
> никто (включая нас самих) не переделывал уже обдуманное заново.

---

## Контекст

Разработка платформы «Дагестан» с нуля. Требования ТЗ: одна кодовая база на
iOS и Android, единый backend, модульность, масштабирование до 50+ городов
и миллиона пользователей, высокий уровень безопасности, российский хостинг.

## Решения

### Мобильное приложение — React Native + Expo

**Почему:** язык TypeScript тот же, что на сервере. Типы данных описываются
один раз в `packages/shared` и переиспользуются и сервером, и приложением —
рассинхронизация между ними становится ошибкой компиляции, а не ошибкой
у пользователя. Разработчиков React Native в РФ существенно больше, чем Flutter.

**Отвергнуто:** Flutter (второй язык в проекте, нельзя переиспользовать код
с бэкендом), нативная разработка (двойная стоимость, прямо противоречит
требованию ТЗ об общей кодовой базе).

### Сервер — NestJS на Node.js

**Почему:** NestJS изначально построен вокруг модулей, что напрямую отвечает
пункту 42 ТЗ: изменение чатов не должно ломать недвижимость. Встроенные
механизмы стражей и внедрения зависимостей закрывают требования по правам
доступа без самописных костылей.

### Формат модулей — ESM

**Почему:** NestJS 12 распространяется **только** в формате ESM, поддержки
CommonJS в нём нет. Оставаться на NestJS 11 ради CommonJS означало бы начать
многолетний проект на предыдущей major-версии и всё равно мигрировать позже,
но уже с большим объёмом кода.

**Следствие для разработки:** в ESM все относительные импорты обязаны указывать
расширение файла — `import { X } from './x.js'`, даже если файл называется
`x.ts`. Это не опечатка, а требование стандарта.

### База данных — PostgreSQL 17 + PostGIS, доступ через Prisma 7

**Почему PostgreSQL:** единая база на все города (пункт 2 ТЗ), надёжные
транзакции — критично там, где считаются деньги. PostGIS даёт географические
запросы «найти всё в радиусе 3 км» без самописной математики.

**Почему Prisma:** описание структуры базы в одном файле, автоматическая
генерация миграций и типов. Запросы параметризуются автоматически, что закрывает
класс атак SQL-инъекции.

**Следствие:** Prisma 7 требует драйвер-адаптер (`@prisma/adapter-pg`), а адрес
базы задаётся в `prisma.config.ts`, а не в схеме.

### Менеджер пакетов — npm workspaces (не pnpm)

**Почему:** pnpm создаёт символьные ссылки в `node_modules`, а сборщик Metro
у React Native работает с ними плохо. Для проекта, который должен собираться
у владельца без бубна, надёжность важнее скорости установки. npm уже установлен
вместе с Node.js — дополнительных инструментов не требуется.

### Проверка данных — Zod 4, собственный пропускной фильтр

**Почему свой, а не готовая библиотека:** сторонние обёртки Zod для NestJS
(`nestjs-zod`) поддерживают NestJS 10–11 и не поддерживают 12. Собственная
реализация — 30 строк, не зависит от чужого графика обновлений. Документация
Swagger строится из тех же схем через `z.toJSONSchema()`, поэтому не может
разойтись с реальным поведением API.

### Ограничение частоты — своя реализация на Redis

**Почему не `@nestjs/throttler`:** он не поддерживает NestJS 12, и, что важнее,
нам нужны нестандартные правила — многоуровневая защита бюджета на SMS с
отдельным суточным потолком по всей системе. Готовый пакет этого не умеет.

### Тесты — Vitest

**Почему не Jest:** связка Jest + ESM + TypeScript до сих пор требует обходных
настроек. Vitest работает с ESM нативно.

## Что осталось открытым

Эти решения сознательно не приняты — они требуют внешних договорённостей
и подтверждения владельца:

| Вопрос | Статус |
|---|---|
| Поставщик данных о погоде (Meteoblue или Яндекс) | ждёт решения по бюджету |
| Поставщик карт (2GIS или Яндекс MapKit) | ждёт подтверждения |
| Источник данных о киносеансах | **блокер**: публичных API в РФ нет |
| Платёжный провайдер | ждёт открытия юрлица |
| Юридическая модель попутчиков (580-ФЗ) | требует консультации юриста |
